# Placement Data Analyzer

## About the Project

Placement Data Analyzer is a Python-based project that analyzes student placement records using Pandas and Matplotlib. It processes placement data, calculates statistics such as average and highest packages, identifies invalid records, and performs branch-wise placement analysis.

The project uses four test cases to demonstrate data processing, validation, analysis, and visualization through pie charts and bar charts.

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV

## Project Structure
- `Codebase` – Contains the Python source code.
- `TestCases` – Contains screenshots of the outputs of all four test cases.
